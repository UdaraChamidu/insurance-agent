  SECTION 4: WHAT THE CLIENT NEEDS BUILT (MISSING PIECES)
================================================================================

--- 4.1: EMPLOYER INTAKE FORM ---
A public-facing form to capture group employer details:
  - Company name
  - Contact person (name, email, phone)
  - Number of employees (total)
  - Number of eligible employees
  - State
  - Industry / SIC code
  - Renewal date
  - Current carrier / plan name
  - Contribution strategy (employer pays %, employee pays %)
  - Benefits needed (medical, dental, vision, life, disability, etc.)

IMPLEMENTATION:
  - New frontend page: /employer-intake or /group-intake
  - New backend model: EmployerLead or GroupLead
  - New API endpoint: POST /api/leads/employer
  - Store in Supabase database
  - Connect to CRM pipeline


--- 4.2: CENSUS COLLECTION TEMPLATE ---
A way for employers to submit employee census data:
  - Employee name
  - Date of birth
  - Gender
  - Zip code
  - Dependents (spouse, children with DOBs)
  - Tobacco use
  - Current coverage (waive/enroll)

IMPLEMENTATION OPTIONS:
  - Option A: Downloadable CSV/Excel template + secure upload
  - Option B: Online form where employer enters rows
  - Option C: Both (template download + upload portal)
  - Secure file upload to Supabase storage
  - Link census to the employer lead record


--- 4.3: GROUP-SPECIFIC CRM PIPELINE ---
Current pipeline: new > appointment_booked > quoted > enrolled > lost
Client needs a 10-stage pipeline for group cases:

  Stage 1:  new_lead           - Lead comes in
  Stage 2:  contacted          - First outreach made
  Stage 3:  discovery_scheduled - Discovery call booked
  Stage 4:  census_requested   - Census form sent to employer
  Stage 5:  census_received    - Census data received back
  Stage 6:  sent_to_warner     - Case sent to Warner Pacific for quoting
  Stage 7:  quotes_received    - Quotes back from Warner Pacific
  Stage 8:  proposal_presented - Options presented to employer
  Stage 9:  closed_won         - Deal closed, onboarding begins
  Stage 9b: closed_lost        - Deal lost (with reason tracking)
  Stage 10: renewal_followup   - Renewal tracking and follow-up

IMPLEMENTATION:
  - Update Lead model pipeline_status enum
  - Update frontend pipeline UI (drag-and-drop board or list view)
  - Add pipeline stage change history/timestamps
  - Add notes per stage transition
  - Add renewal date tracking and reminders


--- 4.4: EMAIL/SMS FOLLOW-UP TEMPLATES ---
Pre-built message templates for the group workflow:

  Template 1: FIRST OUTREACH
    - Introduction, who you are, what you offer
    - Call to action: book a discovery call

  Template 2: MISSED CALL
    - "Sorry I missed you" follow-up
    - Reschedule link

  Template 3: BOOKING CONFIRMATION
    - Confirm date/time/timezone
    - What to prepare (employee count, current plan info)

  Template 4: CENSUS REQUEST
    - Explain what census data is needed
    - Attach or link to census template
    - Deadline for submission

  Template 5: FOLLOW-UP AFTER QUOTE
    - Summary of options presented
    - Next steps
    - Call to action: schedule decision meeting

  Template 6: RENEWAL REVIEW OUTREACH
    - Upcoming renewal notice
    - Offer to review current plan
    - Book renewal consultation

IMPLEMENTATION:
  - New database model: MessageTemplate
  - Admin UI to view/edit templates
  - Variables support: {{company_name}}, {{contact_name}}, {{date}}, etc.
  - Integration with existing email (SMTP) and SMS (Twilio) services
  - Trigger templates from CRM pipeline stage changes


--- 4.5: DOCUMENT ORGANIZATION ---
Client needs organized folder structure per case:

  /Prospecting       - New leads, initial documents
  /Active Quotes     - Cases being quoted with Warner Pacific
  /Sold Groups       - Closed deals, onboarding docs
  /Renewals          - Renewal tracking documents
  /Compliance-Docs   - Permissions, timestamps, compliance records

IMPLEMENTATION:
  - Create folder structure in Supabase storage per employer lead
  - Auto-create folders when a new employer lead is created
  - Move documents between folders as pipeline stage changes
  - Admin UI to browse/manage document folders
  - Link documents to specific employer leads


--- 4.6: SECURE FILE COLLECTION PORTAL ---
A public-facing page where employers can securely upload documents:
  - Census spreadsheets
  - Current plan documents
  - Employee forms
  - Business entity documents

IMPLEMENTATION:
  - New public page: /upload/:token (secured by unique token per employer)
  - File type validation (PDF, Excel, CSV, images)
  - File size limits
  - Upload progress indicator
  - Confirmation email after upload
  - Files stored in Supabase storage under employer's folder
  - Notification to admin when files are uploaded
